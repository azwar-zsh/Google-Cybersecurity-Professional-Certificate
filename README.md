# CREATech Future Talents: Google Cybersecurity Track Professional Training - Notes

Repository ini dibuat untuk mendokumentasikan rangkuman materi yang diselesaikan selama mengikuti program **CREATech Future Talents - Track Cyber Security**. Program ini merupakan Pelatihan Teknologi Masa Depan untuk Peningkatan Kapasitas Talenta Digital Ekonomi Kreatif yang diselenggarakan oleh **GCC X EKRAF** melalui platform **Coursera**.

## Tentang Program
Program ini dirancang khusus untuk memberikan pelatihan tingkat profesional guna membekali peserta dengan keterampilan siap kerja di bidang keamanan siber melalui kurikulum **Google Cybersecurity Professional Certificate**.

*   **Penyelenggara:** GCC X EKRAF
*   **Platform:** Coursera
*   **Sertifikasi:** Google Cybersecurity Professional Certificate
*   **Tujuan:** Meningkatkan kompetensi digital guna memperkuat daya saing portofolio dan resume di industri teknologi secara global.

## Keterampilan Utama yang Dipelajari
Berdasarkan kurikulum program, fokus utama pengembangan keahlian meliputi:
*   **Cybersecurity (Keamanan Siber):** Pemahaman dasar keamanan informasi, mitigasi ancaman, dan kepatuhan siber.
*   **Python:** Penerapan pemrograman Python untuk otomatisasi tugas-tugas keamanan siber.
*   **SQL:** Manajemen database, kueri data, dan analisis log keamanan.
